# 베이킹랩 원본 자산

이 폴더의 GLB, SVG 삽화와 도안은 외부 사진이나 모델을 가져오지 않고 직접 제작했습니다. 모두 CC0 1.0으로 사용할 수 있습니다. 자산별 경로, 크기, 제작자와 이용 조건은 `manifest.json`에 기록되어 있습니다.

## 3D 모델

`models/boule.glb`, `brioche.glb`, `croissant.glb`, `shaping.glb`, `crumb.glb`, `icing.glb`는 GLB 2.0 형식의 실제 바이너리 모델입니다. Y축이 위쪽이며 원점 주변에 배치됩니다. 메시에는 위치, 법선, 인덱스와 PBR 재질이 포함됩니다. 조명과 그림자는 뷰어에서 설정합니다.

성형·기공·구움색은 원리를 설명하는 도형입니다. 물리적으로 정확한 반죽이나 실제 제조 결과를 예측하지 않습니다. WebGL이 없는 환경에서는 각 모델과 이름이 같은 `-poster.svg`와 단계 설명을 보여주세요. 포스터도 실물 사진이 아닌 벡터 삽화입니다.

## 삽화와 인쇄 도안

`illustrations/`에는 여섯 종류의 음식 분류 이미지, 별도의 크루아상 삽화와 재료 역할 지도가 있습니다. 모든 삽화는 640×440 또는 800×460 viewBox를 사용하므로 화면에서 확대할 수 있습니다.

`templates/cookie-heart.svg`, `cookie-star.svg`, `cookie-flower.svg`, `cookie-house.svg`는 A4 실물 크기 도안입니다. 100% 크기와 페이지 맞춤 해제로 인쇄하고, 1cm 검정 눈금을 자로 확인합니다. 종이는 자르기와 모양 확인용 가이드이며 오븐에 넣는 틀이 아닙니다. 식품 접촉에는 적합한 재질을 별도로 사용해야 합니다.

## 다시 만들기

Python 표준 라이브러리만으로 생성합니다. 앱 폴더에서 다음 명령을 실행할 수 있습니다.

```powershell
python public/assets/_source/generate_assets.py
```

자산 생성 코드는 한국어 주석으로 도형 생성과 GLB 저장 방식을 설명합니다. 외부 라이브러리나 네트워크 연결은 필요하지 않습니다.
