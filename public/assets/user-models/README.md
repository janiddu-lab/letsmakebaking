# 내 GLB 넣기

이 폴더에 텍스처까지 포함한 GLB 2.0 파일을 넣으세요. `content/models.json`의 `home`을 `/assets/user-models/my-bread.glb`처럼 수정하면 됩니다.

파일명을 바꾸면 브라우저 캐시와 구분하기 쉽습니다. 외부 텍스처·압축 디코더 없이 열리도록 Draco·Meshopt·KTX 압축을 끄고 내보내세요.

홈페이지의 베이킹 연구실 → 내 3D 오브제에서 업로드하면 폴더를 직접 수정하지 않아도 됩니다. 업로드 자료는 사용자 데이터이며 코드 ZIP에 포함하지 않습니다.
